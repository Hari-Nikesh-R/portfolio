## Overview

Zuzu POS (Android) is a revamped companion to the desktop POS system, extending the workflow to mobile with online capability for monitoring and billing—while storing data to improve sales insights.

## Highlights

- Android app for shop monitoring and billing
- online capability + sync-first workflow for operational continuity
- currently in production (Google Play internal testing)

## Skills / stack

- Flutter, Android
- Cloud Firestore, Firebase
- Android Studio
