## Overview

A tutorial-style project to learn and demonstrate AWS Lambda—how to run code without provisioning servers, and how to design cost-effective, scalable serverless workflows.

## What it covers

- serverless execution with AWS Lambda
- observability using CloudWatch
- API exposure patterns (API Gateway)
- Java ecosystem development workflow

## Skills / stack

- Java, Spring Boot, Gradle
- AWS Lambda, Amazon CloudWatch, AWS API Gateway
