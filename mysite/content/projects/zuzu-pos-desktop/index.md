## Overview

Zuzu POS (Desktop) is a point-of-sale application built to work reliably in offline mode and sync data to the cloud when connectivity is available.

## Highlights

- offline-first billing workflow
- sync-to-cloud architecture for continuity and reporting

## Skills / stack

- Flutter, Windows, Dart
- SQLite, Firebase
