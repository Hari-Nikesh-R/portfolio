## Overview

A professionally designed calendar application built to simplify event organization inside an institution. It focuses on usability, flexible calendar views, and a robust event management workflow.

## Highlights

- multiple views: day, week, month, year
- create/edit/delete events with rich metadata (title, location, time, duration)
- recurring event support (daily/weekly/monthly/custom)
- reminders and collaboration-friendly workflows

## Skills / stack

- Flutter, Dart
- Spring Boot
- MySQL, MongoDB
