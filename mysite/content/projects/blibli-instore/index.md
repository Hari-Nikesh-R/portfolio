## Overview

Blibli Instore brings Blibli’s online checkout experience into physical stores. The merchant app supports in-store transactions using multiple payment methods, helping sellers complete purchases quickly on their own devices.

## My focus

- building and maintaining merchant-facing Android flows
- performance and reliability for day-to-day store usage
- modern Android architecture and async workflows

## Skills / stack

- Android Studio, Java (as needed)
