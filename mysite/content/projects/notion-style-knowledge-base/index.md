## Goal

Build a knowledge base that supports:

- **personal learning notes**
- **community contributions**
- **fast navigation** (dashboard-style homepage + clear sections)

## Information architecture

- Top-level sections: Teaching, Talks, Workshops, Community, Projects, Blog
- Each page should answer: **Outcome → Steps → Links**

## Contribution-friendly defaults

- simple Markdown (no heavy tooling required)
- consistent tags and summaries
- reusable templates (workshops, talks, playbooks)
