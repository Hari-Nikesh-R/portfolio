## Event goals (keep them visible)

- Make newcomers feel included in the first 5 minutes
- Create repeatable formats, not one-off hero efforts
- Help speakers succeed with clear support

## Recommended monthly cadence

- **Week 1**: lightning talks + networking
- **Week 3**: one deep talk (30–45 min) + Q&A
- **Quarterly**: workshop + hands-on lab

## Speaker support checklist

- talk outline review (1 week before)
- demo dry run (optional but recommended)
- recording + slide sharing consent

## Content loop

After each event, publish:

- a summary post in [Blog](/blog/)
- links to [Talks](/talks/) or [Workshops](/workshops/)

If you want to contribute improvements to this playbook, start with the [Community Contribution Guide](/community/community-contribution-guide/).
