## What this roadmap optimizes for

- **Clarity**: fewer topics, deeper practice
- **Consistency**: weekly structure that scales to cohorts
- **Proof**: projects that demonstrate skill, not slides

## Suggested order (12-week baseline)

- **Weeks 1–2**: Java fundamentals + tooling
- **Weeks 3–4**: OOP + collections + debugging habits
- **Weeks 5–7**: Spring Boot (REST, validation, persistence)
- **Weeks 8–9**: Auth basics + Spring Security fundamentals
- **Weeks 10–11**: Testing + performance + deployment basics
- **Week 12**: Capstone + demo day + retros

## Milestone projects

- **API-first**: Task Tracker (REST + DB + validation)
- **Auth**: Role-based access + refresh token flow (simple)
- **Capstone**: Community-centric app (events, posts, contributions)
