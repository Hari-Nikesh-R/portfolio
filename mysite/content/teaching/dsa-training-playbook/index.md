## The system

- **Daily (45–90 min)**: one pattern + 2–3 problems
- **Weekly**: one timed set + one review session
- **Monthly**: one mock interview + gap plan

## Pattern-first list (starter set)

- Two pointers
- Sliding window
- Hashing + frequency
- Stack monotonic patterns
- Binary search on answer
- Trees: traversal + recursion templates

## Review loop (what most people skip)

- Write a 5-line “why I missed it” note
- Save one clean reference solution
- Re-solve the same problem in 7 days

## Pair with your curriculum

- If you’re teaching Java Full Stack, run DSA as a parallel track. Start with the [Roadmap](/teaching/java-full-stack-roadmap/).
