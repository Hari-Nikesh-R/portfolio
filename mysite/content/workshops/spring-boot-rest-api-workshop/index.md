## Outcome

By the end, attendees ship an API with:

- clean request/response models
- validation + error responses
- persistence (JPA or JDBC)
- a small test suite

## Agenda (90–150 min)

- Setup + project structure (10)
- Build endpoint + validation (25)
- Add persistence + migrations (30)
- Testing: slice tests + a happy path (25)
- Wrap: production checklist quick scan (10)

## Exercise prompts

- Add pagination + sorting
- Add a “status” field with allowed values
- Introduce one performance pitfall, then fix it
