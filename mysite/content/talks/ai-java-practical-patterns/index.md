## Audience promise

In 30–45 minutes, attendees leave with **patterns** they can adopt the same week:

- A “prompt → patch → test” workflow
- Guardrails for security + correctness
- A short list of tasks AI is great at (and where it isn’t)

## Outline

- **Why now**: AI as a teammate, not a replacement
- **Good use cases**: refactors, tests, docs, debugging assistance
- **Risk zones**: auth, crypto, licensing, hidden assumptions
- **Team workflow**: PR templates + review checklists

## Demo idea (simple + convincing)

- Take a small Spring Boot endpoint
- Generate tests + edge cases
- Review and harden the result
